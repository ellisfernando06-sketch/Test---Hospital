# Assets del Hospital

## Plantilla de certificado

Coloca aquí la imagen oficial del diploma:

- `certificado_base.jpg` (recomendado)
- o `certificado_base.png`

La plantilla debe ser el marco del **Hospital General** (escudo HG, bordes dorados).

El bot escribe encima:
- Nombre del graduado
- Capacitación
- Fecha y número
- Firmas (encargado + Director de Investigación y Docencia)
