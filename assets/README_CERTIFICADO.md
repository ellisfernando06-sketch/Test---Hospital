# Plantilla del certificado

Coloca aquí el archivo:

`certificado_plantilla.jpg`

(o `certificado_plantilla.png`)

Es la imagen oficial del **Certificado de reconocimiento** del Hospital General.
El bot la usa en `/certificado_oficial` para generar diplomas limpios.

Si existen los módulos `_cert_tpl_part0.py` … en la raíz del repo, al arrancar se genera este JPG automáticamente.
